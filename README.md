# Demand Forecasting & Late Delivery Risk (Supply Chain)

Forecasts daily category-level demand and flags orders likely to arrive late, using [DataCo Smart Supply Chain for Big Data Analysis](https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis)
(Kaggle)

## Project Structure

```
supply_chain_demand_forecasting_project.ipynb   # full analysis
data/                                           # place the Kaggle CSV here
requirements.txt
README.md
```


## How to Run
1. Download the dataset from Kaggle.
2. Place `DataCoSupplyChainDataset.csv` in the `data/` folder.
3. Install dependencies and run the notebook as follows:

```bash
pip install -r requirements.txt
jupyter notebook supply_chain_demand_forecasting_project.ipynb
```
